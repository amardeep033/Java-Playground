## Popular Java Tools and Libraries

| Library / Tool | Category | Use Case |
|---|---|---|
| Apache PDFBox | PDF processing | Java library for reading, creating, splitting, merging, and extracting text from PDFs |
| Caffeine Cache | In-memory cache | High-performance local cache for Java services |
| Jackson | JSON serialization | Convert Java objects to/from JSON; commonly used in Spring Boot APIs |
| Lombok | Boilerplate reduction | Generate getters, setters, builders, constructors, and logging fields at compile time |
| Guava | Core utilities | Collections, caching helpers, string utilities, preconditions, and common Java helpers |
| Apache Commons | Utility libraries | Reusable helpers for IO, Lang, Collections, Codec, CSV, and more |
| SLF4J + Logback | Logging | Standard logging facade and implementation for Java applications |
| JUnit 5 | Testing | Unit testing framework for modern Java projects |
| Mockito | Mocking | Mock dependencies in unit tests |
| Testcontainers | Integration testing | Run real dependencies like PostgreSQL, Redis, Kafka, or RabbitMQ in Docker during tests |
| Flyway / Liquibase | DB migrations | Version-control database schema changes |
| Resilience4j | Fault tolerance | Retries, circuit breakers, rate limiting, bulkheads, and timeouts |
| OkHttp / Apache HttpClient | HTTP client | Make outbound HTTP calls to external services |
| MapStruct | Object mapping | Compile-time DTO/entity mapper with minimal runtime overhead |
| Hibernate Validator | Validation | Bean validation using annotations like `@NotNull`, `@Email`, and `@Size` |
